# AudioQA References

Place local reference WAV files in the class folders below when you want
feature-only comparison:

- `kicks/`
- `snares/`
- `wubs/`
- `growls/`
- `glitches/`
- `risers/`
- `drops/`

References are never samples. They are used only to compute aggregate features
with `ableton-audioqa learn-references`, and generated Ableton material must not
copy, sample, or recreate copyrighted recordings.
